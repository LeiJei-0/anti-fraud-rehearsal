# 第一章《一份周末兼职》：宿舍里的手机通知

需求 #4｜实施前任务书｜范围：第一章｜上轮基线 ff6037b。上轮 79 项断言不代表本轮通过。

**希望玩家看到什么：** 周末下午，一个大学生靠在宿舍上铺玩手机。一条兼职通知亮起。他停住拇指。接下来由玩家决定：放下手机，还是看一眼？打开通知本身不等于受骗。求助一直可用，界面标「演练」，开场不提前揭晓答案。

## 一、连起来看开场，再接管手机

|画面|玩家看到什么|怎样接到下一镜|
|---|---|---|
|引导页 / A01|暖色大学宿舍，暂按「上床下桌」布置。下方书桌、上方床栏交代空间；白色上衣的学生靠着枕头，用手机看内容。|点「开始体验」请求全屏；若未获准，在当前窗口继续。画面沿用引导页构图，镜头从床栏缓缓靠近。|
|A02|拇指原本在滑动；通知出现，手指停下。学生从放松到微微挑眉，用眼神带出消息方向。|不要再从茶几拿起第二部手机。保持床、手、手机的方位一致。|
|A03|画面从肩后靠近同一块屏幕。白色衣袖有浅灰阴影，与枕头分开；指尖停在通知下方。|提示逐渐清晰；与 A04 共用通知内容，切换时不闪白、不重复响铃。|
|A04|屏幕停稳，显示完整通知和可选动作。手托住手机下沿，不盖文字或按钮。|玩家点「查看」才轻点并展开内容；点「先放一放」直接显示「安全离开」。不操作就安静等候。|

保留暂停、跳过、静音与退出。删除课表图案、开场字幕、引导说明、无障碍描述和结尾文案中的旧场景残留；历史版本记录保持原样。白色以服装为主，保留眼、眉、嘴和手指的轮廓，不用夸张惊恐表情。

## 二、手机里的三个修改

- **字留在屏幕里。** 先在双击打开的实际入口复现，找出哪一镜、哪一行、哪个字号越界，保留改前截图。短信和弹幕都给文字留出内边距，长句自然换行。大字时优先增加文字区域高度，必要时允许手机内容纵向滚动；不能用裁掉句尾、整机缩小或强制滚动字幕来掩盖问题。
- **A07 无配音弹幕。** 让自称辅导员的角色出现在画面里；对方说的话以带说话人标识的短句逐条出现，不做观众评论，不安排人声素材或语音合成。静音也能读全；暂停可停留，减少动态时显示静态对白。字幕不得挡住眼睛和行动按钮；玩家可以回看。看过内容只记接收信息，不记已核实。
- **A09 图案配文字。** 校园服务用校门、学校通讯录用联系人本、任务聊天用气泡、回看视频用播放框。图案本地绘制，下面保留文字名，整个图块可点、可用键盘进入。没看过 A07 时，回看入口不伪装成可用按钮。校园入口和对方聊天入口视觉上有区分，点图标本身不算核实。

## 三、什么时候算结束

删除强制播放的结尾动画。进入结算时停止旧动画、声音和定时器，把键盘焦点放到结果标题。首屏能读到「本局结果＋为什么」，需要时再看经过或求助。普通「退出演练」仍可中途退出，不替玩家虚构结局。

|本局发生了什么（由上往下判定）|立即显示|
|---|---|
|确认模拟垫付，即使之前做过核实|出现模拟损失；保留「没有发生真实扣款」、事后求助和只读回看。原确认提示之后可直接查看结算，不再看尾声。|
|到过垫付确认页，最终没有确认|有惊无险|
|没有进入垫付页；查过学校发布记录，也用原有号码取得老师答复|及时核实|
|其余主动结束，包括 A04「先放一放」|安全离开；未核实的事项仍标「待核实」。|

## 四、交给队友怎么试

1. 断网双击 `demo-chapter-1.html`，带上同层 `assets/`。先不解释，让队友说出「人在哪里、在做什么、哪条通知由我决定要不要打开」。没有看懂就记录镜头，而不是提示正确答案。
2. 在 1366×768、390×844 分别试标准、大字、投屏三档。检查动画中间和停稳后的通知，A07 最长一句、A09 图块名；记录读不到的原句，确认无横滚、截字、叠字，操作区不被手挡住。留一段连续开场录像及有代表性的改前/改后截图。
3. 正常播放与跳过开场各试一次：A04 点一次「先放一放」，当下看到安全离开，停留十秒也不二次结算。单独试全局退出，确认不会误当结算。键盘走一次，结果标题应可见。
4. 从 A06 找同学，再去校园核实，返回招聘消息应回 A06；从 A04 发起同样操作则回 A04。仅拨号仍待核实，完成两项才算核实。A10 取消、确认、连点以及事后处理各走一次，不得改变既定结果或重复记账。
5. Qoder 对照原七条路线回归，按新要求替换旧的尾声断言。交付时区分自动实测与尚需真机/投屏的人工项，记录现象、尺寸和证据。队友只需反馈：「在哪一幕／我看到什么／我以为会发生什么」。
