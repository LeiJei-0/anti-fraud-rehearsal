# 拇指滑屏 · 制作验证

双击 `拇指滑屏.mp4` 查看四秒样片。手掌已经握稳手机，拇指从虎口伸向玻璃，向上拖动消息列表一次，随后抬开。第二章来电时的接听操作仍由玩家选择。

`拇指滑屏.r2d.json` 可以用 Rev2D 打开。手机、掌根和其余四指画在固定底片上。拇指单独使用项目里的透明原画，网格左侧驱动指腹，右侧保持掌根固定。消息列表有独立轨道，显示范围被限定在玻璃以内。保留同目录的 PNG 及 `../../film-source/hand-art/swipe-thumb.png`。

制作验证使用 RevStudio/Rev2D 提交 [f144581c](https://github.com/RevStudio/Rev2D/commit/f144581cdf1f12d781379c4df90d262b8c2dfa3d)。在已经安装项目依赖的 Rev2D 检出目录，用 PowerShell 设置模型完整路径后运行：

```powershell
node bin/rev2d.js validate $模型路径
node bin/rev2d.js frames $模型路径 -o out/hand --anim swipe --fps 24 --frames 96
```

实际渲染为 960 × 540 的 96 张 PNG，再按每秒 24 帧编码为 H.264。模型校验报告为 0 个错误、0 个警告。对比第 18 和第 58 帧，以左上为原点，掌根检查区域 x=676…691、y=332…344 的像素值逐一相同。
