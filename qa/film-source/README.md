# 手机响起以前：三章动作短片

这些是配合右侧手机演练的无声短片。在动作分支改变时切片，最后一帧停下等待玩家。录制中不包含现场音或对白，不会替玩家确认交易。

|镜头|节奏|动作|
|---|---|---|
|消息到达|7.25 秒|人物与所在场景 → 近处的手机 → 屏幕亮起、通知或来电出现 → 手靠近。|
|查看线索|6 秒|从看手机的人切到物品与两份材料。后来的材料滑到对照位置，指尖沿视觉线索移动。|
|确认之前|6 秒|拇指/食指靠近手机，在确认动作前停下、收回；镜头回到人物。|

青年：白衣、上铺、床面的织纹、校园卡与校园服务入口。中年：旧相机和照片、傍晚来电、聊天附件与服务条款。老年：上午窗光、茶具、眼镜、纸币与讲座邀请。物件用于叙事示意，判断以手机中实际打开的资料为准。

参考 [painted-animation](https://github.com/tuzhechen2005/opus-video-skills/tree/main/skills/painted-animation) 的关键姿势、动作先后、按时间绘帧和联系表审片做法。这里的离线实现为 Pillow 路径、纹理、局部位移与 FFmpeg，未调用该技能的 p5.js 运行时。人物远景采用本项目现有图版；手势、手机、床面、核对道具等近景由脚本绘制。

**复现**（Python 3：Pillow、NumPy、fontTools、imageio-ffmpeg；Windows 中文字体）：从任意目录运行 `python render.py --sheets ./strips`（脚本路径按所在目录填）。默认使用 Chrome 将章节 SVG 渲染为图版，也可用 `--plates <目录>` 指定已有的 ch2-chrome.png 和 ch3-chrome.png。影片是 960×540、24 帧/秒的 H.264 MP4，兼容直接打开的静态站点。程序只在制作时运行。
